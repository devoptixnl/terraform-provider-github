# github_organization_repositories (Resource)

Resource to authoritatively manage which repositories are active in a GitHub organization.

This resource lists the repositories that stay active in the organization and archives every other repository on apply. Repositories are never deleted or unarchived. It does not create repositories; manage those with [`github_repository`](repository) and reference their names, so the repositories are created before this resource is applied. Applying fails if a listed repository does not exist.

A listed repository that is already archived stays archived; unarchive it with `archived = false` on its `github_repository` resource. Archived repositories that are not listed are ignored.

!> Every active repository not listed is archived on apply, which makes it read-only. A repository managed with `github_repository` but left out of `repository_names` is archived on one apply and unarchived by its `github_repository` resource on the next, until that resource sets `archived = true` or the repository is listed.

When this resource is destroyed it is only removed from the Terraform state; no repositories are archived.

## Example Usage

```terraform
resource "github_repository" "website" {
  name = "website"
}

resource "github_repository" "infra" {
  name = "infra"
}

resource "github_organization_repositories" "example" {
  repository_names = [
    github_repository.website.name,
    github_repository.infra.name,
  ]
}
```

## Import

This resource is imported by the organization name, which must match the provider's `owner`.

Import is supported using the following syntax:

In Terraform v1.5.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `id` attribute, for example:

```terraform
import {
  to = github_organization_repositories.example
  id = "my-org"
}
```

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
terraform import github_organization_repositories.example my-org
```
